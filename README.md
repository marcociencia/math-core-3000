A high-performance calculator with a hybrid Python & C++ backend, featuring a modern dark-themed interface.

🚀 **[Try Math Core 3000 Live](https://math-core-3000-jwdvud23nqkr28jezsgura.streamlit.app/)**

## 🚀 Features

- ⚡ **Hybrid Python & C++ Engine** - Critical operations accelerated with C++ via Pybind11
- 🎨 **Modern Dark UI** - Elegant interface with glassmorphism effects and smooth animations
- 🔗 **Pybind11 Integration** - Seamless Python/C++ binding for maximum performance
- 📜 **Calculation History** - Track your last 10 operations
- 📱 **Responsive Design** - Works perfectly on desktop and mobile devices
- 🛡️ **Error Handling** - Graceful fallback to Python if C++ compilation fails

## 🛠️ Tech Stack

| Technology | Purpose |
